#### Проход 7 — 2026-09-11

Что есть. 7a, физиология сценариев: региональная механика в `deform.js` —
вес зоны w(θ, v) и два состояния сокращения (c, s) и (c₂, s₂), смешанные по
весу; гипокинез (второе состояние ослаблено, интегралы объёма считаются с
весом, объём меша совпадает с кривой < 3 %), несинхронность (второе состояние
запаздывает на `lateralDelay` из карты активации, s основной части решается с
учётом доли, уже имеющей масштаб s₂ — объём точный), истончение стенки
(постоянное отрицательное утолщение). Дилатация приходит из объёмной кривой
сама (s = 1,3 при КДО 200). `cycle.js`: КСО ПЖ следует за УО ЛЖ, накопленный
объём активного опорожнения ЛП (привод ушка, при ФП = 0). `conduction.js`:
второй вход ПНПГ на перегородку (`rvSeptEntry`), `lbbbEndoFactor`,
`stats.lateralDelay` (норма 29 мс, БЛНПГ 74). Ушко ЛП получило сегмент частиц
(петля в слепом мешке), ПМЖВ — маркер окклюзии, ткань — подкраску зоны.
Шесть сценариев в `content/scenarios.js` с текстами-функциями от цикла.
`engine.js` — сборка и `applyScenario` без перезагрузки (кэш карт активации).

табличными цифрами); `ui/pick.js` — ID-проход в RenderTarget ½ разрешения с

#### Проход 5 — 2026-09-10

Что есть: слой кровотока — ~6000 частиц на 22 сегментах путей (`flowpaths.js`):
полые вены → ПП → ПЖ (приток и отток раздельно) → ствол ЛА → ПЛА/ЛЛА; четыре
ЛВ → ЛП → ЛЖ (приток вдоль задней стенки к верхушке, отток через ВТЛЖ) →
восходящая аорта → дуга и ветви. Положение частицы — функция времени:
s = (s₀ + C/A) mod L, где C — накопленный объём через привод сегмента
(`cycle.cumFlow`: ∫max(±dV/dt) по таблице 1 мс; за цикл = УО; `beat.svBefore`
в таймлайне), A — эффективное сечение с учётом доли потока. Через закрытый
клапан частицы не проходят по построению, в изоволюмические фазы камеры стоят,
вены текут равномерно, дистальные артерии — смесь 0,6 равномерного и 0,4
пульсирующего (сток windkessel). Частицы деформируются тем же полем, что
