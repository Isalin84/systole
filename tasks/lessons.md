# Уроки по проекту Systole

Формат: дата — что пошло не так — правило на будущее.

- 2026-09-08 — ES-модули не открываются с file:// в Chrome. Правило: всегда запускать через `python3 -m http.server`, не обещать «двойной клик по index.html».
- 2026-09-08 — Цвет среза был почти неотличим от затенённого серого, и я полчаса искал «ошибку ориентации» там, где её не было. Правило: отладочные цвета делать кричащими (красный), проверять гипотезу одним контрастным тестом до теоретизирования.
- 2026-09-08 — Смещение полости ПЖ вдоль нормали эндокарда ЛЖ у верхушки уводило ПЖ под ЛЖ (нормаль там смотрит вниз). Правило: толщину стенки откладывать по нормали, а соседние полости — по горизонтальному радиусу от оси.
- 2026-09-08 — Острия серпа ПЖ протыкали эпикард в бороздах, потому что толщина стенки ПЖ на остриях вырождалась в ноль. Правило: у масок стенок оставлять угловой запас за краем сектора.
- 2026-09-08 — В панели браузера Claude ES-модули кэшируются между перезагрузками одной страницы; правки в main.js не подхватывались. Правило: перед перезагрузкой уйти на другой URL (например /styles.css) и вернуться.
- 2026-09-08 — rAF в скрытой панели браузера заморожен, fps на экране «0–4». Правило: производительность мерить синхронно: N × renderer.render + gl.finish.
- 2026-09-08 — В browser_batch падение любого шага скрывает все скриншоты пакета. Правило: рискованный JS выносить в отдельный вызов, скриншоты — в пакет без него.
- 2026-09-08 — «Уйти на другой URL и вернуться» не гарантирует свежие модули: cut.js остался старым, и я решил, что плоскость не работает. Правило: dev-сервер отдаёт `Cache-Control: no-store` (serve.py), а не полагаться на трюки с навигацией.
- 2026-09-08 — Лог консоли в панели браузера копится по вкладке через перезагрузки; 256 старых WebGL-предупреждений выглядели как живая ошибка. Правило: для чистой проверки открывать новую вкладку (tabs_create) или перехватывать gl.drawElements + getError прямо в странице.
- 2026-09-08 — Скриншоты панели зависят от её размера (бывает 363×230). Правило: снимать через systole.shot(name, w, h) → POST /shot → PNG в scratchpad, потом Read.
- 2026-09-08 — Стержень с одним сегментом и двумя полюсами даёт сетку без колец и индексы за пределами буфера. Правило: у tubeSurface с полюсами segments ≥ 2; gridSurface стоит проверять nRings ≥ 1.

12. Позиционное поле деформации: признак «в секторе ПЖ» по углу не отличает
    эндокард ЛЖ от поверхности перегородки — нужны веса по радиусу
    (wSep = smoothstep(0, w₀, ρ − ρ_endo)), иначе полость ЛЖ получает
    утолщение перегородки и объём расходится с кривой. Тест на объём меша
    поймал это сразу; без него ошибку было бы видно только на разрезе.
13. Масштаб серпа ПЖ нельзя выводить «по аналогии» с ЛЖ (V ∝ k·s): дуга
    серпа масштабируется почти как перегородка, а не как полость. Выводить
    k из честного интеграла объёма серпа (квадратное уравнение).
14. Утолщение стенки по радиусу у полюса (ρ → 0) уводит полюс с оси;
    у верхушки утолщение направлять вдоль оси.
15. `node --test test/` в Node 22 не находит файлы — нужен glob
    `node --test 'test/*.test.mjs'`.
16. В тестах «ворота ⇔ градиент» исключать ±1,5 мс вокруг границ фаз: там
    градиент равен нулю по построению и знак не определён.
17. В zsh `echo =====` падает («= not found») — разделители печатать через printf.

18. Плоская палитра прячет ошибки ориентации: у оболочек предсердий нормаль
    смотрела внутрь, «внутренняя» поверхность была снаружи, объём считался по
    ней. Проверять знак нормали относительно центра тела сразу при построении
    оболочек (`dot(n, p − c) > 0`).
19. Позиционная деформация требует согласованных атрибутов глубины на всех
    мешах, которые касаются друг друга: вырожденное кольцо с d = 0 и d = 1 на
    совпадающих вершинах после деформации раздвигается. Для совпадающих
    точек — одинаковый d.
20. Нулевые нормали (вырожденные треугольники) + normalize в шейдере = NaN =
    чёрные пиксели. Ставить защиту `dot(n, n) > eps` перед нормализацией.
21. Первый вариант процедурного материала всегда слишком контрастный:
    насыщенность, SSS, bump и «жир» уменьшать в 2–3 раза от первой оценки и
    проверять на общем плане, а не только вблизи.
22. GPU-время мерить через EXT_disjoint_timer_query_webgl2 при целевом
    разрешении; `gl.finish()` на Metal/ANGLE не блокирует и даёт 0,2 мс.

23. Всё, что должно быть воспроизводимо на скрабе, делать функцией времени,
    а не интегрированием: частицы крови идут по накопленному объёму через
    клапан (табличный интеграл dV/dt), и «через закрытый клапан не проходят»
    получается бесплатно.
24. Кэш по округлённому ключу (цикл по RR) требует, чтобы и источник (удар)
    использовал округлённое значение, иначе конец удара не совпадает с концом
    цикла (разрыв 0,3 мс дал скачок на полный УО).
25. Периодическая функция в точке t = RR: wrap даёт 0, а нужен конец; для
    накопленных величин обрабатывать t = RR явно.
26. В тестах на «ничего не проходит» между моментами сравнивать целые мс
    (floor), если таблица с шагом 1 мс, иначе ловится доля первого шага.

27. Униформа, объявленная в вершинной части onBeforeCompile, во фрагментной
    не видна: нужна отдельная декларация; ошибка компиляции three пишет в
    консоль, а сцена молча остаётся пустой. После правки шейдера первым делом
    читать console errors.
28. Псевдо-ЭКГ из карты активации чувствительна к скорости сети Пуркинье:
    0,3 см/мс даёт 10-мс «иглу» R (весь эндокард за 20 мс), 0,15 — реалистичный
    QRS ~60–80 мс. Скорость сети — эффективная по эндокарду, не скорость волокна.
29. Нормировать ЭКГ по окну QRS, а не по всей таблице, иначе при блокаде
    дискордантный T перетягивает масштаб.

30. Бандл .app, у которого вместо исполняемого файла shell-скрипт, на macOS 26
    из Finder и через `open` молча не стартует (прямой вызов скрипта работает,
    в системном логе пусто). Собирать лаунчер через `osacompile` (апплет с
    настоящим Mach-O, `do shell script`) и подписывать ad-hoc. `spctl --assess`
    отвергает любую ненотаризованную сборку — не критерий; проверка = `open`
    и строка в логе. Песочница Bash прячет чужие процессы и порты, так что
    `lsof`/`open` внутри неё не показательны — проверять без песочницы.
31. У лаунчера всегда должен быть лог и диалог при сбое: «нажал, ничего не
    случилось» без следа не диагностируется. Из Finder PATH без Homebrew.

32. Униформы MeshPhysicalMaterial в three r170 загружаются только при смене
    материала (или программы); менять их в onBeforeRender для одного меша из
    пачки бесполезно. Подсветка одного меша — вариант материала с тем же
    customProgramCacheKey. У ShaderMaterial есть uniformsNeedUpdate — им
    пользуется ID-проход через overrideMaterial.
33. Полноэкранные снимки интерфейса в панели браузера Claude непригодны при
    эмуляции 1440×900 (кадр масштабируется в угол); headless Chrome
    (`--headless=new --screenshot --virtual-time-budget`) даёт честный кадр,
    но без результатов асинхронных операций WebGL (подписи по ID-буферу).
34. При смешении двух состояний сокращения по весу объём меша совпадает с
    кривой только если s решать из интегралов с тем же весом; «второе состояние
    из другого момента» тоже решается точно, если его масштаб считать
    известным и подставлять в квадратное уравнение.
35. Тест на «нормальный» показатель, посчитанный новой метрикой, надо сначала
    измерить, а не задавать порог из головы: lateralDelay в норме оказался
    29 мс, а не «< 15».

36. **Абсолютные пути ломаются в подкаталоге.** `fetch('/shot')` работал на
    localhost в корне, но на GitHub Pages сайт живёт в `/systole/`. Правило:
    в статическом проекте все ссылки относительные, включая те, что в коде.

37. **Headless Chrome без флагов SwiftShader рисует только каркас.** Снимок
    вышел 11 КБ: разметка есть, сцены нет, потому что `--disable-gpu` убивает
    WebGL2 и `createEngine` падает до монтирования интерфейса. Нужны
    `--enable-unsafe-swiftshader --use-gl=angle --use-angle=swiftshader`.
    Правило: пустой тёмный снимок — сначала проверить WebGL, а не деплой.
