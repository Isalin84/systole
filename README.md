# Systole — интерактивный атлас работающего сердца

Трёхмерное сердце, которое бьётся в реальном времени: диаграмма Виггерса, ожившая в 3D.
Давления в камерах, объём левого желудочка, ЭКГ, тоны и положение створок — одна и та же
фаза цикла, показанная разными способами одновременно.

Демонстрация: https://heart.bestpracticeai.ru/

## Что внутри

- **Геометрия строится кодом.** Ни одной внешней модели и ни одной растровой текстуры:
  камеры лофтингом по сплайновым сечениям, сосуды трубками по кривым, клапаны с честным
  числом створок, хорды и папиллярные мышцы, коронарные артерии в бороздах эпикарда.
- **Движение выводится из времени в миллисекундах от QRS.** Продольное укорочение,
  радиальное утолщение и скручивание считаются в вершинном шейдере как поле в
  координатах сердца. Морф-таргетов и запечённых кадров нет.
- **Клапаны открываются от давления, а не по таймеру.** Положение створки определяется
  знаком градиента через неё, поэтому изоволюмические фазы возникают сами собой,
  а при смене сценария тайминги перестраиваются без правок.
- **Проводящая система.** Карта активации от синусового узла до волокон Пуркинье,
  ЭКГ выводится из неё же, волна деполяризации и кривая синхронны по построению.
- **Шесть сценариев** без перезагрузки: покой, нагрузка, фибрилляция предсердий,
  сердечная недостаточность со сниженной фракцией выброса, окклюзия передней
  межжелудочковой ветви, блокада левой ножки пучка Гиса.
- **Разрез** четырёхкамерный, по выносящему тракту и по короткой оси через clipping planes.

Физиологические константы собраны в `src/physiology.js` с источником у каждой величины.
Геометрический объём полости сверяется с кривой объёма тестами, а не на глаз.

## Запуск локально

Модули не грузятся с `file://`, нужен любой статический сервер:

```bash
python3 serve.py
```

Дальше http://localhost:8000/. Сборки нет, npm не нужен.
Параметры адреса: `?scenario=rest|exercise|af|hfref|lad|lbbb`, `?hr=`, `?cut=`, `?dev=1`.

## Тесты

```bash
node --test 'test/*.test.mjs'
```

Проверяются кривые цикла, таймлайн, деформация с интегралами объёма, проводящая
система и сценарии.

## Стек

three.js 0.170 с CDN, собственные GLSL-шейдеры, ванильный JavaScript, без сборщика.
Внешние ресурсы только два: three.js и шрифт IBM Plex Sans.

## Оговорка

Учебная модель, а не медицинское изделие. Гемодинамика не решается численно:
кривые давлений заданы по литературным данным. Цифры и формулировки требуют
вычитки практикующим кардиологом перед показом.
